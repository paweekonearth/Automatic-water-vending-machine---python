##เครื่องขายน้ำอัตโนมัติ

**วัตถุประสงค์**

-เพื่อเพิ่มความสะดวกสบายต่อลูกค้า  
-เพื่อคำนวณราคาสินค้ารวมได้อย่างถูกต้อง  
-เพื่อให้ผู้ใช้สามารถตรวจสอบราคาสินค้าได้ง่าย  

**กลุ่มเป้าหมาย**

-นักเรียนและบัคคลากรในวิทยาลัย
-ร้านค้าขนาดเล็ก

**ฟังก์ชัน**

-รับราคาสินค้า
-รับจำนวนสินค้า
-คำนวณ
-แสดงราคารวม
